# 2x2 FF EG OneLook Trainer

Welcome to the **2x2 FF EG OneLook Trainer**, a modern web application designed to help speedcubers master the 2x2 cube, specifically focusing on the First Face and EG (CLL, EG1, EG2) methods. This project is a migration and enhancement of previous training tools, built with **React**.

## Features

### 🟦 First Face Trainer
Master the first step of the 2x2 solution.
- **Randomized Cases**: Infinite practice with generated scrambles and cases.
- **Visual Feedback**: See the setup and solution visually.
- **Swipe Controls**: Interactive swipe gestures to navigate through cases.
- **Keyboard Support**: Use arrow keys for quick navigation.
- **Algorithm Card**: Detailed view of the setup and solution algorithms.

### 🟩 EG Recognition Trainer
Train your recognition speed for EG sets (CLL, EG1, EG2).
- **Sequence Mode**: Watch a sequence of colored stickers to identify the case.
- **Answer Phase**: Test your knowledge by selecting the correct OLL, Orientation, and Permutation (PLL).
- **Timer**: Track your recognition speed.
- **Customization**: Adjust object duration and pause times to match your skill level.
- **History**: Review your recent performance.

## Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **State Management**: React Hooks (useState, useEffect, usage of custom hooks like `useOrientation`)

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js installed on your machine.
- npm (Node Package Manager).

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/Ayator/2x2-FF-EG-OneLook.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd 2x2-FF-EG-OneLook/frontend
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```
